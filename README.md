# نظام الأرشفة الإلكترونية وإدارة الوثائق الرقمية (IT-EDMS)
## Enterprise Electronic Document & Record Management System

نظام متكامل واحترافي لإدارة وحفظ وأرشفة الوثائق والمستندات التقنية والإدارية، تم تطويره بأحدث التقنيات ليوفر تجربة مستخدم عصرية بمعايير أمان وتشفير عالية وتوافق كامل مع المعايير المؤسسية.

---

### 🚀 المميزات الرئيسية (Key Features)

1. **إدارة الوثائق والأرشفة الرقمية**:
   - ترقيم آلي للوثائق وفق سياسات وترميز متقدم (IT-DOC-{YEAR}-{SEQ}).
   - تصنيف الوثائق، وتحديد مستويات السرية (عام، داخلي، سري، سري للغاية).
   - سحب وإفلات ورفع المرفقات المتعددة مع فحص البصمة الرقمية (SHA-256).
   - فلترة وبحث سريع وفوري بالعنوان، الرقم، التصنيف، الحالة، والقسم.
   - تصدير كامل بيانات الوثائق إلى ملف Excel / CSV بترميز UTF-8.

2. **سير العمل والاعتمادات (Approvals & Workflow)**:
   - نظام اعتمادات متعدد المراحل للمدراء والمخولين.
   - إمكانية القبول أو الرفض مع كتابة الملاحظات والتعليقات الإدارية.

3. **الهيكل التنظيمي والشجري (Departments & Branches)**:
   - إدارة الإدارات العامة والأقسام الرئيسية وتوزيع الفروع والشعب والوحدات التابعة لها بشكل هرمي تفاعلي.
   - إمكانية الإضافة والتعديل والحذف والطي والتوسيع للفروع.

4. **طباعة الاستمارات الرسمية والملصقات الميدانية**:
   - **استمارة التوثيق الرسمية (A4 Archive Sheet)**: مطابقة للمواصفات الحكومية والمؤسسية مع باركود متجهي عالي الدقة، وختم الاعتماد، وتوقيعات الاستلام.
   - **ملصق الباركود الميداني (Thermal Barcode Sticker)**: مخصص لطابعات الاستيكرات والباركود لرفوف وأدراج الحفظ المادي.

5. **سجل التدقيق الأمني والنزاهة (Audit Trail)**:
   - تسجيل ومراقبة غير قابلة للتعديل لكل حركة (تسجيل الدخول، إنشاء، تعديل، اعتماد، أرشفة، تحميل).
   - عرض التوقيت الدقيق بالصيغة الدولية مع عنوان الـ IP والبيانات السابقة والجديدة (Diff).
   - تصدير سجل التدقيق إلى ملف CSV.

6. **إدارة المستخدمين والصلاحيات (RBAC)**:
   - أدوار متعددة: مدير عام النظام (Super Admin)، مدير تقنية المعلومات (IT Manager)، مسؤول أرشفة (Archivist)، مشاهد (Viewer).
   - ربط المستخدمين بالأقسام والفروع مع إدارة تفعيل/تعطيل الحسابات.

### 💻 البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend)**:
  - React 19 + Vite 8
  - Tailwind CSS + Lucide Icons + React Hot Toast
  - Zustand لإدارة الحالة والمصادقة
  - تصميم Dark Glassmorphism عصري فائق الجمال يدعم RTL بالكامل.

- **الواجهة الخلفية (Backend API)**:
  - Laravel 11 Framework
  - MySQL Database + Eloquent ORM
  - Laravel Sanctum للمصادقة الآمنة عبر الـ Tokens
  - معمارية RESTful API محكمة ومحمية بالصلاحيات (Gates & Policies).

### 🛠️ طريقة التثبيت والتشغيل المحلي (Setup & Run)

#### 1. متطلبات التشغيل:
- PHP >= 8.2 (مع تفعيل إضافات: pdo_mysql, mbstring, openssl)
- Composer
- Node.js >= 18 & npm
- خادم MySQL

#### 2. تشغيل الواجهة الخلفية (Backend):
`ash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8000
`

#### 3. تشغيل الواجهة الأمامية (Frontend):
`ash
cd frontend
npm install
npm run dev
`
افتح المتصفح على: http://localhost:5173
