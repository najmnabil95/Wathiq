# سيريل — كِلن آند ليف

لوحة تحكم كاملة لمتجر صغير، بأسلوب «الزجاج السائل» المستوحى من واجهة iPhone: خلفيات كرات ملوّنة ضبابية، بطاقات شفافة، وضع داكن وفاتح، وبيانات تجريبية محفوظة في المتصفح.

مشروع مستقل داخل هذا المستودع في المجلد `cirrel/`، مبني بـ **React 19 + Vite 7** وCSS خام (بدون مكتبة مكوّنات أو مكتبة رسوم).

---

## التشغيل

```bash
cd cirrel
npm install
npm run dev
```

ثم افتح `http://localhost:5174`.

```bash
npm run build     # نسخة الإنتاج في cirrel/dist
npm run preview   # معاينة نسخة الإنتاج
```

> يوجد في `vite.config.js` المسار النسبي `base: './'`، والتطبيق يستخدم `HashRouter` ليعمل من أي مسار أو استضافة ثابتة دون إعداد إعادة توجيه.

## الصفحات

| المسار | الصفحة | أبرز التفاعلات |
|---|---|---|
| `/` | لوحة التحكم | نطاقات الرسم (سنة / 6 أشهر / شهر / أسبوع)، هدف الشهر القابل للتعديل، طابور التغليف، النواقص، مصادر البيع |
| `/orders` | الطلبات | فلاتر وبحث، تحديد متعدد، تصدير CSV، جدول أو لوحة سحب وإفلات، مرتجعات، طلب جديد |
| `/products` | المنتجات | شبكة/جدول، تصنيفات، فلاتر مخزون، إعادة تخزين، منتج جديد |
| `/analytics` | التحليلات | مؤشرات، رسم إيرادات، دونات، قمع الدفع، أجهزة، أفضل الصفحات |
| `/customers` | العملاء | شرائح، بحث، ملف جانبي، تقييمات، عميل جديد |
| `/finances` | المالية | نظرة عامة، أرباح وخسائر، مدفوعات، مصروفات جديدة |
| `/invoices` | الفواتير | حالات، تذكير، تعليم كمدفوعة، فاتورة جديدة |
| `/discounts` | الخصومات | إنشاء كود، تفعيل/إيقاف، نسخ، حملات |
| `/chats` | المحادثات | قنوات الموقع/إنستغرام/الرسائل، إرسال ردود، ملف العميل |
| `/email` | البريد | فلاتر، قراءة، نجمة، رد، إنشاء رسالة |
| `/apps` | التطبيقات | ربط/فصل التكاملات، ويب هوك |
| `/settings` | الإعدادات | بيانات المتجر، التنبيهات، المظهر، النسخ الاحتياطي |
| `/help` | المساعدة | بحث، أسئلة شائعة، تذكرة دعم |

## الميزات العامة

- **الوضع الداكن/الفاتح** مع حفظ الاختيار، والافتراضي داكن.
- **شريط جانبي قابل للطي** إلى أيقونات، وقائمة منسدلة على الجوال.
- **⌘K / Ctrl+K** لبحث شامل في الصفحات والطلبات والمنتجات والعملاء مع تنقل بلوحة المفاتيح.
- **بيانات تجريبية دائمة**: الطلبات، المخزون، الفواتير، الأكواد، المحادثات، الإعدادات — تُحفظ في `localStorage` تحت `cirrel:state:v2`.
- **إشعارات Toast**، نوافذ منبثقة، أدراج تفاصيل، ومخططات SVG مكتوبة يدويًا.
- **عربي بالكامل وRTL**: كل النصوص والبيانات التجريبية بالعربية، والقائمة الجانبية على اليمين، مع خط عربي محلي واحترام اتجاه الكتابة في الجداول والنماذج والأرقام والمعرّفات.

## البنية

```
cirrel/
├─ src/
│  ├─ App.jsx                 # المسارات
│  ├─ store.jsx               # الحالة + localStorage + الإجراءات
│  ├─ data/sample.js          # كل البيانات التجريبية والدوال المساعدة
│  ├─ components/
│  │  ├─ Icons.jsx            # مجموعة أيقونات SVG
│  │  ├─ ui.jsx               # Card / Button / Modal / Drawer / Toggle…
│  │  ├─ charts.jsx           # AreaChart / Sparkline / Donut / Radial…
│  │  └─ layout/              # Sidebar / Topbar / CommandPalette / Toasts
│  ├─ pages/                  # 13 صفحة
│  └─ styles/                 # base / layout / components / dashboard / pages / rtl
└─ index.html
```

لا توجد مفاتيح API ولا اتصال خارجي. كل شيء يعمل محليًا.
